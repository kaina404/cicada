# British IPA data

Source: https://github.com/open-dict-data/ipa-dict

Original file: data/en_UK.txt (Received Pronunciation)

Bundled for offline reading aids. The app chooses the first listed pronunciation,
skips familiar vocabulary and prioritizes difficult words and technical overrides.
A graduating Chinese high-school reading aid annotates each selected word only once per answer.
Word length and a familiarity list are practical filters, not a measured proficiency classifier. This is a dictionary,
not an official Chinese school vocabulary-level classification. Unknown words stay plain.

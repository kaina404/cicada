# 面试附和不重写回答：2026-11-08

原因：`CoachInterruption.classify` 原先只匹配少量完整短语。`Okay` 会跳过，但 `OK, all right, continue`、单独的 `Continue` 和中文连续附和会落入 continuation，触发取消和重新生成。

修复：整句必须能完整分解为附和、语气词或无附加要求的继续短语，才跳过重算。支持重复、组合、大小写、标点及中文无空格连接；不使用子串命中来忽略整句话。句中存在新主题、条件、纠正或问题时仍走原来的更新逻辑。原始发言继续保存。

# ActAI 钱包面试实时模拟（动态追问 + 两处改题）

2026 年 11 月 19 日。Cicada macOS Dev 1.10.1，`bcafb1c+`（当前工作树重新编译）。英文教练卡片，DeepSeek Flash 实际请求。按 90 分钟题档顺序，`PACE=1` 按语速念题和念卡。

## 方法

- 面试官：题档固定题 + DeepSeek 扮演的 Founder。Founder 根据候选人刚念出的原话生成 **8 处动态追问**，并在 **W3、W6 两处改题**时点名候选人原方案中被推翻的部分。
- 候选人：逐句念教练卡片（`meSaid`），卡片 THEN 不是“等面试官”时按一次“下一张”，TYPE 写上白板（`coachOCR`）。
- 每轮由另一个 DeepSeek 评委按题档要点判定；结束后 Founder 按题档评分表打分。
- 文字注入，不经过系统音频和语音识别。

## 结果

20 轮全部生成新卡片；评委判定 16/20 通过。首字中位数 754 ms（546–1,094 ms），从注入到卡片稳定中位数 5.8 s，最慢 12.6 s。评分表 75 分，“推荐”刚过线，四项均为 3 级。

## 发现的问题

1. **无视面试官给定事实**（W6）：明确说没有可靠金额，卡片仍让助手推断金额。属于“编业务规则”，最需要修。
2. **授权边界只在客户端**（W6/追问）：多次没讲服务端绑定收款人和金额校验授权。题档把“由客户端决定扣款或允许模型绕过授权”列为暂不推荐红线。
3. **幂等语义**（W3）：“拒绝重复”与“返回原交易当前状态”不同。卡片自己的补充行提到了应带回结果，但正文说的是拒绝。
4. **W5 会话隔离**连续两轮缺失：缺会话代数和丢弃过期回调。
5. W3 卡片截图正文下方出现一个红色 🚫 图标，未查明来源。

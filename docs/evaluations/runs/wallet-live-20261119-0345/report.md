# ActAI 钱包面试实时模拟：修复后复测

2026 年 11 月 19 日。Cicada macOS Dev 1.10.1，`bcafb1c+`，当前工作树编译。英文教练卡片，DeepSeek Flash 实际请求。按 90 分钟题档顺序，`PACE=1` 按语速念题、念卡。基线见 [wallet-live-20261119-0056](../wallet-live-20261119-0056/report.md)。

## 方法

- 面试官：题档固定题，加 DeepSeek 扮演的 Founder。Founder 根据候选人刚说的话插入 8 处动态追问，并在 W3（丢响应后杀进程）和 W6（改从群聊发起）两处点名推翻候选人原方案中的具体一步。
- 画图：W2 要求画架构**流程图**，W2-seq 要求画转账**时序图**，W3 改题要求更新时序图，W6 改题要求把新入口画成**流程图**。脚本检查卡片 TYPE 的图类型。
- 候选人：逐句念卡片；卡片表示还有下一步时按一次“下一步”；图的代码写上白板。
- 每轮由另一个 DeepSeek 评委按题档要点判定，结束后 Founder 按评分表打分。

## 修了什么

| 问题（基线） | 最终轮表现 |
| --- | --- |
| W6 聊天里没有可靠金额，卡片自己推断了金额 | “I'd never guess the amount”，展示两个 Alex 让用户选，金额由用户填写 |
| 授权只在客户端 | 服务端把授权绑定到付款方、收款方、金额和有效期，聊天文字不能授权 |
| W2 缺金额用分、原子扣贷和最终余额 | 8000 分，同一事务扣 A 贷 B，A 从 100 到 20，B 从 0 到 80 |
| W3 说服务端“拒绝重复请求” | 同 ID 返回原交易记录；查不到也保持“结果未知” |
| W5 没有会话隔离 | 每个请求带账号和会话代数，过期响应直接丢弃，并补了一张时序图 |
| W7 缺验收和暂停 | 有范围、签收人、排查和暂停新转账 |
| W1 只问“是否一致” | 问了用户、余额权威、离线行为三个问题 |
| 截图里的 🚫 | 调试截图不再画原生按钮 |

代码改动：`CoachCardPrompt` 增加“面试官给定的事实必须遵守”“多问逐项回答”“澄清问题”“Android 架构图拆分层次”等规则；加入金额、切账号、发布三类话题提示，开新题时不附旧题提示。祈使句请求按提问处理。`CoachCards` 能识别 “What questions do you have for me” 和 “Let's switch to the design”；“back to …” 只看那一句，而且只有比当前题更匹配时才切回旧题。`scripts/test.sh` 672 项通过。

## 仍未解决

- 第一张卡片把 Founder 开场议程里的“设计钱包”记成了当前题，第二张卡片就纠正了，卡片内容不受影响。
- 评委对多要点标准偶尔放宽（如 W7 验收清单）；单轮全过不代表每次都稳定。
- 文字注入不经过系统音频和语音识别；真人麦克风、实际共享窗口和完整 90 分钟时长仍待验收。

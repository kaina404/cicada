# ActAI Android 钱包面试 QA

2026 年 11 月 19 日。Cicada macOS Dev 1.10.1，`bcafb1c+`，在当前工作树编译并通过代码签名校验。测试使用英文教练卡片和实际 DeepSeek Flash 请求。以 90 分钟题档安排全场顺序，旧版题档提供钱包追问素材。

## 结果

13 轮连续问答均生成新卡片。首字耗时中位数 686 ms，范围 440–1,017 ms。脚本从注入到判定卡片稳定的中位数为 4.9 s，最慢一轮为 21.2 s，开场日志显示有额外系统转写和请求。停会后确认当前题目、卡片和上一场记录状态已清空。

| 环节 | 观察结果 |
| --- | --- |
| 钱包主链路 | 成功渲染确认、提交、账本和结果的时序图，余额结果为 A 剩 20 USD、B 收到 80 USD。 |
| 第一次改题 | 入账后丢响应并杀进程。教练提议提交前持久化原请求 ID、重开后查询权威结果，并生成修改后的时序图。缺少查询仍未明确时的用户反馈。基于教练回答追问同一 ID 改金额，教练正确要求拒绝且不改账。 |
| 余额竞争和切换账号 | 教练正确判断两笔独立转账中只有一笔成功，并说明账号隔离。切账号追问要求提出验证，卡片未给出延迟旧响应的测试方法。 |
| 第二次改题 | 增加群聊入口。教练引导用户确认 Alex 身份和金额，也给出了独立意图 ID。卡片没有说明断流后如何查询交易状态。基于确认流程追问重复调用且金额被改，教练要求拒绝并重新确认。 |
| 交付和收尾 | 首批范围、灰度和待确认监控均有覆盖。异常处置只给出排查和原 ID 重试，缺少暂停新增转账、对账、责任人及恢复条件。反问环节生成了两条相关问题。 |
| 项目归属 | 教练把旧页面返回键故障归给 KKday。本机已确认话术把该案例记录在德邦证券。这轮判失败。 |

## 系统音频补测

另开一场，通过 macOS 播放一段 11.89 s 的合成英文追问。应用经系统音频和 Apple 语音识别生成了恢复方案卡片。自开始播放到脚本观察到稳定卡片为 16.3 s，卡片首字为 841 ms。完整问答采用加速文本及白板文字注入。真人候选人麦克风、实际共享窗口和完整 90 分钟连续运行仍待验收。

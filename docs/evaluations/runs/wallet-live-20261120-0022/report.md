# ActAI 钱包面试：把评分表从 75 推到 90 以上

2026 年 11 月 19–20 日，三场完整的 DeepSeek 面试：[2232](../wallet-live-20261119-2232/)、[2327](../wallet-live-20261119-2327/)、0022。Cicada macOS Dev 1.10.1。题目、Founder 动态追问、两处改题和严格评委与 [2144](../wallet-live-20261119-2144/report.md) 相同，没有放真实声音。

## 为什么一直是 75

- 评分表按 0–4 级打四项，总分 = 权重 × 等级 ÷ 4。之前 19 轮里有 18 轮是四项全 3 级（75），只有 1413 是全 4 级（100）。
- 4 级要求“有反例、测试或生产证据支撑”。2144 被扣在“纸面上强但没有证据”，以及几处只讲到大概。
- 1413 的驱动在念完最后一句后，会再等最多 8 秒读续写，共读了 87 条续写；1516 以后的驱动没有这段等待，只读了约 20 条。续写里正好是 4 级要的内容：计数器、重装丢 ID、30 分钟升级、每 15 分钟发一次进展。

## 改了什么

| 来源 | 修法 |
| --- | --- |
| 驱动少读了续写 | 恢复“念完再等续写，最多 8 秒”（测试侧，更接近真人看着卡片念） |
| 设计题没有证据 | 设计题每题用一句证据支撑主要决定：故障测试、会出错的情况和对应的防护，或一个告警阈值 |
| 项目题没有结果 | 项目题带一个资料里原样给出的结果数字 |
| 2232：卡片说“这个数字是我自己定的，不是实测”“说实话我没有生产证据” | 数字当作计划来说，不加免责声明；“怎么知道有效”先讲证据，再讲它的局限，以及弥补局限的那项检查 |
| 2232：续写前后矛盾（查不到记录先说报错，又说保持未知） | 同一题后面的卡片只补充，不推翻前面已经说过的话 |
| 2232：第一题的续写开始设计钱包 | 议程里后面的题，面试官没问就不讲；钱包提示只看面试官最后一句，讲个人经历的题不发 |
| 2327：W7 请求每秒重启一次，45 秒只显示半句 | 面试官没有新内容时，不打断正在生成的面试官请求（`CoachCards.receive`）；每次重启记日志 |
| 2327：第一题还没记录题目，钱包补句又补上了 | 必答点只用面试官最后一句判断题目类型 |
| 2232、2327：W2 时序图没说金额用分 | 给出具体金额的转账题，必补“金额用 Long 存，单位是分” |

## 结果

| 轮次 | 评分表（当场 / 复评 temperature 0 / 复评 0.7） | 严格评委（第一张卡 / 按实际念出） | 新卡 | 首字中位数 | 卡片稳定（中位 / 最慢） |

| 2144 | 75 / 75 / 75 | 19 / 20（共 21） | 21 | 647 ms | 6.0 / 24.0 s |
| 2232 | 75 / 81.25 / 75 | 20 / 18 | 21 | | |
| 2327 | **93.75** / 93.75 / 88.75 | 17 / 17 | 19 | | |
| 0022 | **100** / 100 / 75 | **19 / 20** | 21 | 559 ms | 5.0 / 8.2 s |

- 0022 剩下的失败：
  - P2-change 续写里出现了“重试最多三次”。资料里有 “three” 出现在附近别的词旁边，数字检查没拦住。
  - W1 第一张卡没有提出 MVP，按实际念出时补上了。
  - W5 第一张卡缺切换账号的要点，按实际念出时通过。
- “面试官没说新内容就不重启”这道保护在 0022 里触发了 2 次；另外 4 次重启都是面试官说了新内容。
- 评分表本身波动很大：同一份 0022 记录，temperature 0 给 100，0.7 给 75。最近两场 temperature 0 都在 90 以上，但还算不上稳定达标。

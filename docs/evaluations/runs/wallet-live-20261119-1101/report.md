# ActAI 钱包面试：严格评分和真实音频复测

2026 年 11 月 19 日。Cicada macOS Dev 1.10.1，`aba95cb+`，当前工作树编译。题档、Founder 动态追问和两处改题同 [0345 轮](../wallet-live-20261119-0345/report.md)。

## 这次改了什么测法

- **评委改严。** 原来评委只要答到“至少两个要点”就判通过，0345 轮因此 21/21。现在 `judge(strict=True)` 要求逐条列出每个必需要点，任何一条是 no 就判失败。用严格评委重判 0345 轮，只有 15/21 通过。
- **评委能看到候选人资料。** 它能看到简历和 App 知识库里的个人资料、过往公司和项目，所以“约 1 秒”“Bugly”“每天约 30 万次规划”不再被误判为编造。
- **评委的判定规则更精确。**
  - 同一金额换单位也算对，例如 2000 美分就是 20 美元。
  - 判定行写成“PASS: FAIL”这种自相矛盾的情况，按失败处理。
- **面试官用真实声音提问（`AUDIO=1`）。**
  - 面试官的话由 Samantha 念进 BlackHole 2ch，用户听不到。
  - 声音经过系统音频采集，再由 Qwen3-ASR 识别（本机设置是 Qwen+Hy），然后才生成卡片。
  - 候选人一侧仍然是直接注入文字。

## 修了什么

| 问题（在哪发现） | 修法 |
| --- | --- |
| 第一张卡片把开场议程记成题目（0345 P1） | 议程（“we'll start with…, then…”）不开题；开新题时以真正问的那句为准 |
| 一句话问三件事，卡片只答两件（P2、W1、P3） | 拆出每个小问，按顺序写进提示；多问时卡片上限放宽到每问两句、最多 8 句 |
| 识别把问号识别成句号（“…as the MVP.”） | 按开头的疑问词判断是不是问句 |
| 识别把一道题切成几行，提示只看最后一行（W7 只剩“Do in the next half hour.”） | 面试官连续说的几行合成一个回合，候选人开始念以后也用这个回合 |
| 画图请求被切开后，后半句像“只讲解”，图被删掉（1007 W2） | 判断要不要画图、是否只讲解时，看整个回合 |
| 题目的后半句识别得晚，替换掉已经完整的卡片（1035 W7） | 提示模型：已答全就 KEEP，否则保留还没念的要点 |
| 画面外的声音一直被判为“有人在说话”，卡片等了 37 s（0812 W1） | 最后一个新词之后最多再等 4 s |
| 一声“Oh.”换掉正在念的卡片（0812 P2） | 卡片在屏幕上时，单纯的附和不再触发新卡片 |
| 识别出的乱码短句盖过真正的问题（“Who do you remote?”） | 提示模型答前面那个真正的问题，不要请面试官重复 |
| “下一步”卡片重复刚念完的话（W3、W4、W6） | 从面试官最新一句开始算已经说过的内容，代码里再删一遍重复的句子 |
| 钱包题漏点（金额、并发、丢响应、聊天支付、切账号、发布） | 话题提示里列出每类必答点，例如：行锁或条件更新、先存转账意图、按账号加客户端 ID 查询、重复 ID 返回原交易、工具调用重试对应同一个意图、切账号后从 A 的历史恢复、发布前的检查和恢复条件 |
| 澄清需求只提问不给 MVP（W1） | 同一张卡片里要给出 MVP 假设，上限 6 句 |
| 讲过往经历不说公司（P3） | 第一句就说在哪家公司 |
| “怎么知道改动有效”不讲证据的局限（P2） | 要说证据来源和它证明不了什么 |

`scripts/test.sh` 679 项全部通过。

## 仍未解决

- **还有固定的几个漏点。** 最终几轮常见的漏点：
  - W6 没说“工具调用重试对应原来的转账意图”，每轮都漏；
  - W7 漏“何时恢复”；
  - P2 漏“证据的局限”；
  - W1 的第一张卡片常常不给 MVP（念的过程中，后续卡片会补上）；
  - W2 偶尔把客户端画成一个框。

  这些要点都在提示里，但模型在 5–6 句里经常顾不全。最后两条提示（客户端分四个框、余额写成数字并带确认步骤）是最终轮之后才加的，还没有实测。
- **测试没有覆盖念卡过程中的更新。** 驱动只评第一张稳定卡片加一次“下一步”。候选人念卡时卡片会更新（例如 W1 在第 28 s 补上了 MVP），这部分不计分，所以严格分数偏低。
- **真实声音只覆盖面试官一侧。** 候选人一侧仍然是注入文字。真人麦克风、Zoom 或 Meet 里的真实面试官，以及完整 90 分钟，都还没测。
- **测试时不能有别的声音。** 系统音频会收进电脑上的所有声音，测试时电脑上不能放视频。

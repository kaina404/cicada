# 手机局域网遥控

1. 手机和 Mac 连接同一个可信 Wi-Fi。
2. 在 Mac 打开悬浮回答，点底部手机图标，再点「生成配对码」。
3. 用手机系统相机扫码，在浏览器打开网页；也可复制配对链接到手机浏览器。
4. 开启 Mac「陪读」并连接 Mac 耳机后，网页支持上一句、按住播放、下一句。按住约 0.4 秒开始播放，松手暂停；切句不播放。声音只从 Mac 耳机输出。
5. 稿件逐词高亮并自动滚动。网页稿件区域的滑动不会移动 Mac 浮窗。竖屏和横屏均可使用。手机网页禁用双指缩放和双击放大。
6. 自动回答未及时更新时，点「重新生成」，Mac 会取消旧请求，基于最新问题重新生成答案；无需开启陪读，正在生成时也可再次请求。没有问题内容时按钮不可用。
7. 要看桌面，在 Mac 手机菜单选择「向手机共享 Mac 主屏幕」，再点网页的「Mac 屏幕」。Mac 需有屏幕录制权限。该功能只预览主屏幕，不控制其他 App。

页面保持打开时会自动重连。配对凭证只存在当前页面内存，不写入 cookie、localStorage 或 sessionStorage。刷新、关闭或点「断开」后需重新扫码。二维码凭证只放在 URL fragment，打开后立即从地址栏移除；不进入 HTTP 请求 URL。不要转发配对链接；局域网 HTTP 没有传输加密。

普通局域网 HTTP 页面不能可靠禁止自动锁屏。长时间看稿请调整手机的自动锁屏时间。网页切后台、失去焦点、触摸取消时请求停止播放，Mac 的 0.5 秒播放心跳超时与控制手势超时提供断线兜底。重新进入页面不会自动开始播放，需重新按住。

关闭 Mac 悬浮回答会清除手机稿件并停止远程播放。隐藏浮窗、Mac 锁屏或睡眠、撤销配对均停止屏幕共享。Mac 重启后需要重新开启共享。Mac「断开手机」撤销凭证，「重新生成配对码」使旧链接失效；网页「断开」仅清除当前页面连接。

网页文件位于 `Resources/remote/`，随 Mac App 一起打包，Mac 现有局域网接收端提供固定资源入口 `/remote`、`/remote.css`、`/remote.js`。状态、控制和图片继续使用原有带凭证请求头的接口。原生 iPhone App 同样支持「重新生成」，可在 App 内扫描或粘贴同一个配对链接；Mac 默认二维码在系统相机中打开网页。

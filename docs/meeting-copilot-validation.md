# 会中问答与持续助手开发回执

日期：2026-11-06。环境：Apple M4 Pro、48 GB，macOS 26，开发版同时使用系统音频识别；本机模型取设置中的 `screenModel`（本次为 Gemma 4 E4B QAT 4bit）。未提交、未发布，保留了原有未提交的 v1 实现。

## 实现范围

- P0-1：多模态 user 内容先图后文；最新合格帧有效期 2 秒，最后一页缓存有效期 300 秒，长边 1280。开关关闭时选图返回空；设置预览也不在开关关闭时捕获。
- P0-2：300 秒原文背景，发言上限 4000 个 Swift `Character`，按整条从旧向新淘汰，提问仍取对方最近 20 秒及半句。
- P0-3：保留静止触发，并加 5 秒变化检测 → OCR → novel 后才读模型。问答/助手任务优先，取消在途读屏；运行和目标代次防止取消后的旧结果写回。
- P0-4：回答固定英文；整行完成后另队列调用 `TranslationService.appleOnly`，仅使用已安装的 Apple Translation 语言包。默认开启中文对照，关闭后只显示英文；不可用时只写 `ask: zh gloss unavailable`，不下载、不弹窗、不走 Google/Ling。
- P0-5：完成的手动回答和自动回应建议写入 `speaker=ai` 行，英文先保存，中文完成后更新；共用行号计数器，时间不早于最后一行。纪要、语音翻译、声纹和 SRT 排除 AI；历史问答改取最近三条 AI 行；当前回答保留到替换或关闭。
- P1：最近三页文字含原始 OCR、800 字纪要与单列术语、本场最近三次问答、灰色不确定事实、超 2 秒下一次不带图的护栏。
- 第 7 节：默认开启持续助手，事件规则、防抖、优先级队列、同类更新取消、周期/切换局势、首见术语、新页讲解和跟进提醒。事实和建议分别解析，最多一张强调卡、强调间隔 20 秒；局势周期 60 秒，显式话题切换立即更新。助手状态与辅助卡片只在内存中，结束会议清空；手动回答和自动回应建议以 AI 行随记录保存。手动问答保留且优先。
- P2 未实现，按 PRD 留待后续。

## Assistant 问题修订（2026-11-07）

Cabinet / CabinetAI 产品定位 product: personal affairs and knowledge assistant; Tell → Cabinet handles → Review / Decide → Result. Natural-language requests go to central Secretary coordinator for understanding, planning and delegation to domain agents, each with independent context and self-review before tool calls. Goal: reduce copying information among expense, reminder, task and learning tools, retain context and return decisions to the user.

Cabinet / CabinetAI information architecture 页面: Today shows current tasks, pending approvals and sourced attention items, grouping reminders and tasks with near-due items first. Ask is the bottom full-screen conversation entry, expanding schedule/expense/learning/approval workspaces as needed. Cabinet at top right contains materials, memories and business records. Settings at top left covers privacy, device data, theme and language.

Cabinet / CabinetAI five agents 能力: EXPENSE Chancellor records and categorizes expenses and handles budgets in natural language; REMINDER Private Secretary offers time-confirmation cards, changing time, copying to system Reminders, undo and FCM push; TASK Delivery handles to-dos and deadlines. Secretary coordinates, rather than a single agent owning all domains.

Cabinet / CabinetAI KNOWLEDGE Provost RAG 知识 引用: imports TXT and PDF, including scanned PDF transcription by a vision model; retrieval-augmented answers cite original paragraphs and state missing evidence when material is insufficient. MEMORY Archivist uses Mem0 for long-term preferences and facts; users can inspect, correct and delete them, and deleted content must disappear from both retrieval paths.

Cabinet / CabinetAI extensions 行程 天气 照片 语音: implemented/production-or-validated capabilities in the supplied analysis include research then day-by-day itinerary cards, attraction images and per-day map switching (Shanghai three-day example; one simulator generation took 20.39 seconds, not a production latency percentile). Weather clarifies the city before a card and supports Celsius/Fahrenheit. Photo attachments and voice-to-text input supported.

Cabinet / CabinetAI device capabilities V1 设备 日历 健康 审批: reported live 2026-10-27, reads system calendar, reminders and health data (activity, sleep, heart rate). Calendar/reminder changes are proposals and execute only after the user clicks Apply. One change has one button; multiple changes or any deletion require item selection; deletion items default unchecked. AI privacy consent is required before sending to AI; data deletion/account management do not require AI.

Cabinet / CabinetAI reliability 可靠性 幂等 重试 时区: product principles reflected in code/acceptance criteria: clarify ambiguous dates; never report unsupported success (no article body means not collected, disconnected calendar means not rescheduled, heard does not mean mastered). Preserve successful partial results and retry only failed parts; idempotent submissions and double approval execute once; invalidate stale approvals when underlying data changes. External actions require approval by default; V1 excludes payments/transfers/purchases. Reminder ordering uses account-local calendar date; four timezones and daylight-saving transitions were validated. Principles/acceptance criteria do not establish every workflow passed real-provider end-to-end tests.

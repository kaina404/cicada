# ActAI Android 岗位面试测试场景

依据：用户于 2026-11-06 提供的 ActAI Android Software Engineer 职位说明。以下为按 JD 编写的合成练习与验收场景，不是已核实的公司真题，也不推断公司内部实现。

## 范围

会中问答、持续助手、读屏、上下文回忆与模型知识评估统一采用此面试背景：Them 是面试官，Me 是候选人；产品背景为少提示、主动式的 agent-first 移动通信应用。应用仍只开发与验证 Mac 端，目标环境 Apple M4 Pro、48 GB 内存；无需修改或研究 Android 移植工程。

底层音频、翻译、存储、安全等通用回归测试继续保留各自的行为断言，不为替换场景削弱覆盖。历史报告保留原始输入与结果，不能视为新题库已通过。

候选人的工作年限、具体项目、Play Store 发布经历和实测收益未经提供时，必须明确未知；可以说明解决方案，不可代编个人经历。JD 提到的技术栈不等于 ActAI 实际 API 或架构。

## 输入与验收

- `python3 tools/copilot-audio-fixture.py` 生成五分钟英文练习音频与逐句时间清单。4 个问题、2 个顾虑，包含流式聊天、Flow 生命周期、Binder、TensorFlow Lite、重复发送和监控；其余陈述应避免误触发回答。
- 开发版在听时播放生成音频，检查自动响应、话题切换、术语、手动抢占、取消后无旧结果、结束后无状态残留，以及英文主内容和中文对照。此步骤为合成音频自查，不是真实面试验收。
- `AskTests.swift`、`CopilotTests.swift` 使用 Android 面试语料验证原有解析、窗口边界、流式、调度和隐私行为。
- `CICADA_TEST_ASK=1 scripts/test.sh --filter AskModelTests` 使用合成面试指标表，验证 OCR/图片及四分钟前的 `850 ms` 目标回忆。需要本机模型服务，默认离线单元测试不会运行该项。
- `python3 tools/copilot-eval.py --model <本机模型名>` 运行全部题目，保留首字、总时延、原回答、错误及人工评分。仅为独立知识评测，不代表应用端到端成功。

人工逐题按 `expected_points` 评分：0=错误或无有效回答；1=部分正确且存在关键遗漏；2=覆盖关键点并说明场景权衡。另记无依据的经历/公司事实、错误建议、冗长或回避。关键词命中不算正确率，首字快不算答案正确。报告需分别列出有效回答数、错误数、人工评分和延迟样本；失败请求不能从分母移除。

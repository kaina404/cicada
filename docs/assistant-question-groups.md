# Assistant 问答单元

2026-11-06，Mac。

- 以触发发言的标识关联参考回答、术语和跟进提醒，不按生成时间猜关联。两分钟后的提醒保留原问题标识；被高优先级回答打断的任务恢复时也保留关联。
- 每个单元显示原问题与会内时间，支持整组折叠；使用 SwiftUI Section 固定滚动中的问题标题。会议概况保持独立，避免把整场总结误挂到最后一个问题。
- 保留最近 12 个问题单元；同一来源同类型更新替换旧内容。信息流仅保存在本场内存中，参考回答仍按既有流程存入会议 AI 行。
- 参考回答要求模型直接用第一人称写出可说出口的回答，跟随原问题语言，不再输出“建议提到……”一类指导。通用技术知识不能改写成用户做过的项目，缺失的个人经历使用 `[fill in: ...]` 标记。
- 中文原文不再重复送英文到中文翻译；其他语言由系统语言识别后交给既有苹果本机翻译。语言包仍需已安装。
- 新的独立发言不会仅因时间相邻而自动并入旧问题；跨发言的语义追问归并尚未实现。
